1. Plain-Language Definition

StarkLLM includes eight distinct, professionally designed visual palettes that transform the entire user interface with a single click. From pure zero-black contrast for OLED displays to vibrant cyberpunk pink and translucent frosted glass, you can customize your workspace to match your mood and lighting environment.

2. Why It Exists

Technical research, document analysis, and coding sessions often span many hours. Static, monochromatic dark interfaces can cause visual fatigue. By providing tailored contrast levels and aesthetic variety, StarkLLM ensures prolonged focus and visual comfort.

3. Design System & CSS Token Architecture

Themes are implemented entirely using modern CSS custom properties attached to the root document attribute ([data-theme="..."]):

  • Design Tokens: Tokens such as --bg-app, --bg-card, --accent, --accent-hover, --accent-rgb, and --border-subtle harmonize every component dynamically.
  • Liquid Glassmorphism: The Liquid Glass theme applies dynamic CSS backdrop filters (backdrop-filter: blur(16px)) with translucent RGBA surface layers and glowing borders.
  • OLED True Black: The OLED Pitch Black theme eliminates dark grey tints in favor of absolute #000000, turning off pixels on OLED panels to conserve power and maximize contrast.

4. Instant Switching & Zero Latency

You can change themes from two convenient locations:

  1. Sidebar Quick Palette: Click the Palette icon (🎨) at the bottom of the sidebar to reveal a fast popover menu and select any theme instantly without navigating away from your chat.
  2. Settings → Appearance: View the full responsive Theme Gallery with live color swatch indicators, Persian and English labels, and detailed descriptions.

All theme selections are saved in localStorage, guaranteeing zero-latency persistence across sessions.
