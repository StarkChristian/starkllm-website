Global Knowledge Base

Your personal, persistent reference library.

1. Plain-Language Definition

The Global Knowledge Base is a persistent vector index of documents mapped directly from a designated local folder on your Windows PC.

2. Why It Exists

Professionals often have a core set of reference material (SOPs, code snippets, research papers) that they need to access constantly across multiple different projects.

3. What Breaks Without It

Without a global base, you would have to manually re-upload the same reference PDFs into every single new workspace you create, duplicating data and wasting time.

4. How StarkLLM Implements It

StarkLLM polls a mapped local directory at regular intervals (approximately every minute). It recursively extracts and embeds all supported text files and PDFs, storing them in a dedicated global collection in ChromaDB. New or modified files are re-indexed automatically on the next poll cycle.

5. User-Visible Benefit

You have a single source of truth that is automatically available to query from any chat session, regardless of your current workspace.

6. Practical Example

You map your Obsidian markdown vault to StarkLLM. You can now ask questions about your personal notes while simultaneously analyzing a newly uploaded PDF in a fresh workspace.
