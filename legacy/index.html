Research Beta — Windows

Private Windows AI for Your Local Documents

StarkLLM is a private Windows research beta for technical users to chat with local documents and a personal Knowledge Base via Ollama. Built for developers, researchers, and privacy-conscious professionals who want local RAG running on their own Docker + Ollama stack.

  • 🎯 Deep Hybrid RAG:
    BM25 + Vector embeddings + TinyBERT Cross-Encoder Reranker for pinpoint citation accuracy.
  • 🖥️ Native Desktop v2.0.0:
    Runs in an isolated, sleek desktop window (Cursor/Claude style) with splash screen and zero browser tabs.
  • ⚡ Local Code Sandbox:
    Safe in-process Python execution environment with AST validation and timeout protection.
  • 🔌 Local OpenAI Server:
    Standard /v1/chat/completions endpoint to connect Cursor, Claude Code, and external tools.

⚠️ Before You Download — System Prerequisites

  • OS: Windows 10/11 with WSL2 enabled.
  • Docker Desktop: Installed & running in system tray.
  • Ollama: Installed natively on Windows host.
  • Hardware: 8 GB RAM min / 16 GB recommended (NVIDIA GPU with 8GB+ VRAM recommended).
  • Models: ollama pull qwen2.5:7b & nomic-embed-text (or lighter: qwen2.5:3b)

How StarkLLM Compares

An honest look at how StarkLLM fits into the local AI landscape alongside other popular open solutions.

Inference GUI

LM Studio

Model Runner & Tuning: Superb for downloading GGUFs from Hugging Face and fine-tuning GPU layer offloading. However, it lacks deep multi-document RAG, persistent workspace knowledge bases, and safe code execution.

Best for: Testing raw GGUFs without document grounding.
Basic RAG App

AnythingLLM

Document Chat: Popular for desktop RAG, but relies on naive chunking without cross-encoder reranking, often causing retrieval hallucinations on dense technical documents. Runs inside a heavier web-style dashboard.

Best for: Casual document chats where retrieval precision isn't mission-critical.
Minimalist Chat

Jan.ai

Open Source Clean Chat: A lightweight, zero-telemetry ChatGPT clone. However, it lacks advanced hybrid RAG, cross-encoder reranking, in-process code sandboxing, and multimodal document analysis.

Best for: Simple zero-telemetry chat without document workflows.

⚡ Setup Steps

If Docker, Ollama, and the models are already installed, setup takes about 5 minutes. First-time model and Docker-image downloads depend on your bandwidth.

  1. 1 Start Docker Desktop — Ensure Docker Desktop is running in your system tray.
  2. 2 Install Ollama & pull models — In terminal, run:
    ollama pull qwen2.5:7b
    ollama pull nomic-embed-text
  3. 3 Run StarkLLM Setup (.exe) — Download and run StarkLLM-Setup.exe (or extract Portable ZIP). The wizard automatically configures desktop shortcuts.
  4. 4 Launch & Enjoy — Click the StarkLLM desktop shortcut. Services start automatically and open http://localhost:5173 in your browser.

Important Notes

  • ⌛ First launch: First launch can take several minutes while Docker images download. Once containers are up, the app itself may need 1–2 minutes while the backend finishes startup.
  • ⚠️ Windows SmartScreen: If execution is blocked, use More info → Run anyway or run start.cmd.
  • 💻 Hardware matters: Speed and answer quality depend heavily on having a capable GPU (8GB+ VRAM recommended).

Safe In-Process Local Tools

Phase 2 brings tool-calling capabilities to StarkLLM without security compromises. Models can inspect workspace files, search your personal Knowledge Base, or fetch exact citation passages with complete transparency.

  • Human-in-the-Loop Confirmation: Every tool execution requires your explicit approval. Review and modify arguments in the confirmation card before running.
  • Server-Side Execution Gate: Single-use token verification prevents unauthorized direct execution and protects against replay attempts.
  • Prompt Injection Defense: Vector chunks with embedded tool delimiters are stripped before prompt formulation, neutralizing malicious retrieval payloads.

The Architecture of Privacy

StarkLLM offers an offline alternative to cloud AI services. Your enterprise data, legal briefs, and personal research stay strictly on your machine.

Local Inference

Powered by Ollama, Large Language Models run directly on your own CPU or GPU. Designed to work fully offline once models are downloaded.

Local Storage

Your documents are chunked and embedded into a local ChromaDB vector store running inside an isolated Docker container.

Zero Telemetry

The Windows app has no telemetry and no analytics SDK. This marketing website uses self-hosted Umami; see Datenschutz.
