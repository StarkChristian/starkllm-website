隐私

隐私从设计开始，由您亲自核查。

StarkLLM的设计使您的文档永远不需要云服务。哪些内容上网由您决定，每一个连接您都能看到，而且您不必只听我们怎么说。

永远不会离开您电脑的内容

无论您开启什么功能，这些内容都留在您自己的硬盘以及您自己的处理器或显卡上。

您的文档

信件、合同、书籍、扫描件、照片和录音，以及从中识别出的文字。

您的聊天

问题、回答及其来源，除非您自己选择了云端模型。

搜索索引

每个文档的段落和向量，以及大型文档的摘要。

AI模型

它们通过Ollama在您的电脑上运行。首次下载之后，StarkLLM无需联网即可工作。

收件箱和截止日期

寄件人、金额、账户和日期由您电脑上的规则找出。

不收集关于您的任何信息

没有遥测，没有崩溃报告，没有使用统计，没有广告，也不需要在服务器上注册账户。

哪些内容会上网，以及何时上网

StarkLLM可能建立的每一个连接，与“Settings › Privacy & network”（设置 › 隐私和网络）中所列相同。每个连接在您开启或启动之前都处于关闭状态，或者只是为了您要求的下载而进行一次。

一个开关：完全离线

“Settings › Privacy & network”（设置 › 隐私和网络）中的“Fully offline”（完全离线）会拒绝所有在线功能，关闭与您手机和中继的连接，并且不下载任何内容，连更新也不下载。您的文档、收件箱和本地模型照常工作。首次启动时会询问一次：保持在线还是完全离线。

静态数据保护

可选功能，位于“Settings › Protection”（设置 › 保护）：针对笔记本电脑丢失、同一台电脑上的其他用户，或存放在云文件夹中的备份。

局限它无法防范在StarkLLM打开期间以您的身份运行的恶意软件。仍然建议使用BitLocker：它还能保护程序和模型。

在硬盘上加密
文档、聊天、名称和标题在硬盘上加密，搜索索引也可以锁定。密钥与您的Windows账户绑定。
启动口令
可选的口令，附带恢复密钥。口令从不保存。
加密备份
一个备份文件，您可以存放在任何地方，包括云文件夹；没有口令，它就只是一堆乱码。每周自动备份会保留多个副本。

签名的安装包

从2.1.2起，安装程序、StarkLLM.exe、卸载程序和引擎的程序文件均使用颁发给“Open Source Developer Christian Stark”的Certum证书签名。内置的更新程序只安装以此名称签名的更新。

亲自核查

您不必相信StarkLLM自己的界面。打开“Fully offline”（完全离线），使用应用，然后查看。

  1. 资源监视器按Win + R，输入“resmon”，打开“网络”选项卡。开启完全离线后，StarkLLM.exe、python.exe和ollama.exe应该只与127.0.0.1通信。
  2. PowerShell列出所有不指向本机的已建立连接，以及建立连接的程序：
    Get-NetTCPConnection -State Established |
  Where-Object { $_.RemoteAddress -notin '127.0.0.1','::1' } |
  ForEach-Object { $p = Get-Process -Id $_.OwningProcess -ErrorAction SilentlyContinue
    [pscustomobject]@{ Process = $p.ProcessName; Remote = "$($_.RemoteAddress):$($_.RemotePort)" } } |
  Sort-Object Process, Remote | Format-Table -AutoSize
  3. Wireshark最彻底的检查：在您的网络适配器上抓包，并过滤掉本地流量。然后打开网络搜索，看着DuckDuckGo出现，这样您就知道检查是有效的。
