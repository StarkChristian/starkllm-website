Setup steps

StarkLLM brings its own engine; Docker Desktop and WSL2 are not needed. The first start downloads the AI models you do not have yet (about 5 GB) and, if you let it, Ollama; later starts take seconds.

  1. Run the StarkLLM installerDownload and run StarkLLM-v2.5.0-Setup.exe. The installer contains the engine and creates desktop shortcuts.
  2. Start StarkLLMClick the StarkLLM shortcut. The app starts its engine and checks Ollama.
  3. Install Ollama if it is missingIf Ollama is not installed, the window offers "Install Ollama for me": StarkLLM downloads the official installer from ollama.com (about 2 GB), checks its signature and installs it; no administrator rights are needed. You can also install Ollama yourself from ollama.com.
  4. Wait for the first startStarkLLM downloads the AI models (by default qwen2.5:7b and nomic-embed-text, about 5 GB; suitable models you already have in Ollama are used), shows the progress and then opens in its own window. If something is missing, the window says what and how to fix it (logs: %APPDATA%\StarkLLM\engine.log and engine-native.log).
  5. Create your accountRegister the first account; it is the administrator of this installation (backup and restore). Then create a workspace and upload a document.

Prerequisites checklist

Before you start StarkLLM, confirm that all of the following are in place:

  • OS: Windows 10 or 11 (64-bit).
  • Software: Only Ollama, for the AI models. StarkLLM can install the official version for you ("Install Ollama for me"), or you get it from ollama.com. Docker Desktop and WSL2 are not needed since v2.2.
  • Models and disk: Downloaded automatically on the first start (about 5 GB). Keep at least 15 GB of free disk space.
  • Hardware: Minimum 8 GB RAM (3B models), 16 GB recommended (7B models). An NVIDIA GPU with 8 GB+ VRAM is strongly recommended; since v2.3 StarkLLM also lets Ollama use integrated AMD Radeon and Intel Arc/Iris graphics. The manual has hardware tier guidance.
  • Supported formats: PDF, DOCX (with tables), PowerPoint (PPTX), EPUB e-books, TXT, Markdown, CSV, XLSX, JSON, XML, logs, HTML and images (PNG, JPG with OCR).

Code signing: how to check the installer

Since v2.1.2 the installer, StarkLLM.exe and the uninstaller are signed with a Certum code signing certificate issued to "Open Source Developer Christian Stark", with a timestamp. The signature lets Windows verify the publisher and shows that the files were not changed after signing. The built-in updater only installs updates signed with this name.

Check the signature yourself

  1. Right-click the downloaded installer (StarkLLM-v2.5.0-Setup.exe) and choose Properties.
  2. Open the Digital Signatures tab. The signer must be "Open Source Developer Christian Stark".
  3. Select the signature and click Details. Windows must say "This digital signature is OK".

Some third-party Electron components inside the app (DLL files) are not signed by us. That is intended: the installer, StarkLLM.exe and the uninstaller are signed.

Windows still shows a warning (SmartScreen or Smart App Control)?

The signature lets Windows verify the publisher, but Windows can still warn about a file it has not seen often. Check the publisher name as described above and compare the SHA-256 checksum. If both match, you can continue (in SmartScreen: More info, then Run anyway). If the name is different, the Digital Signatures tab is missing or the checksum does not match, do not run the file: download it again from this page and tell us at info@starkllm.com. Do not turn off Smart App Control, SmartScreen or any other security setting to install StarkLLM.

Frequently asked questions

Does my data leave my computer?

StarkLLM is designed to keep your data on your machine. Documents are stored in a local ChromaDB database on your PC, and AI inference runs through Ollama on your PC. Nothing leaves your PC unless you turn on or start an optional online feature (web search, a web task, a cloud model provider, the update check). Settings › Privacy & network lists every connection, and "Fully offline" refuses all of them.

Is StarkLLM free?

Yes. It is free and open source under Apache 2.0 for personal, research and commercial use. No subscriptions, telemetry or hidden tiers. Provided "as is" with no warranty.

Why can answers be slow?

Speed depends on your hardware. Without a dedicated GPU, Ollama falls back to CPU inference, which is much slower. A dedicated NVIDIA GPU with 8 GB+ VRAM generates much faster.

Is the installer signed? What if SmartScreen or Smart App Control warns me?

Yes. Since v2.1.2 the installer, StarkLLM.exe and the uninstaller are signed by "Open Source Developer Christian Stark", so Windows can verify the publisher. If Windows still warns, check the publisher name (right-click the installer, Properties, Digital Signatures) and compare the SHA-256 checksum on this page. Run the file only if both match. Do not turn off Smart App Control or any other security setting.

What hardware do I need?

Minimum 8 GB RAM for 3B models, 16 GB RAM for 7B models. For power-user models (14B to 32B), 24 GB VRAM or 64 GB system RAM is recommended.

What is the difference between normal chat and document chat?

Normal chat relies only on the model's pre-trained knowledge. Document chat uses RAG: it searches your uploaded documents first, feeds the relevant chunks to the model, and answers with verifiable citations.

What is the difference between workspace documents and the Knowledge Base?

Workspace documents are isolated to one project. The Knowledge Base is a persistent, global folder on your machine that any chat can reference.

The window says "StarkLLM could not start". What now?

StarkLLM starts its own engine and Ollama. When a step fails, the window lists what is missing (for example Ollama not installed, a busy port, a program file Windows blocked, or an engine error with its last log lines) and has a Retry button. The logs are in %APPDATA%\StarkLLM (engine.log, and engine-native.log for the engine). The Help page lists the fixes.

What if the app opens but chat does not connect?

The chat needs Ollama. If the window said "StarkLLM is running without its AI runtime", install or start Ollama and press Retry; StarkLLM then downloads the models (qwen2.5:7b and nomic-embed-text). The engine talks to Ollama on your PC at 127.0.0.1:11434.

Can I inspect the source code?

Yes. StarkLLM is fully open source on GitHub at StarkChristian/StarkLLM under the Apache 2.0 license.
