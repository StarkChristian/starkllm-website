プライバシー

設計からプライベート。ご自身で確かめられます。

StarkLLMは、ドキュメントがクラウドを一切必要としないように作られています。何をオンラインにするかはお客様が選び、すべての接続を確認でき、私たちの言葉をうのみにする必要はありません。

PCの外に決して出ないもの

何をオンにしても、次のものはご自身のディスクと、ご自身のプロセッサーまたはグラフィックスカードの上にとどまります。

ドキュメント

手紙、契約書、本、スキャン、写真、録音、そしてそこから読み取ったテキスト。

チャット

質問、回答、その出典。ご自身でクラウドモデルを選んだ場合を除きます。

検索インデックス

すべてのドキュメントの箇所とベクトル、そして大きなドキュメントの要約。

AIモデル

Ollamaを通じてPC上で動きます。最初のダウンロードの後は、StarkLLMはインターネットなしで動作します。

受信トレイと期限

差出人、金額、口座、日付は、PC上のルールによって見つけ出されます。

お客様に関する情報は何も

テレメトリー、クラッシュレポート、利用統計、広告、サーバー上のアカウントは一切ありません。

オンラインになるもの、そのタイミング

StarkLLMが行いうるすべての接続を、「Settings › Privacy & network」（設定 › プライバシーとネットワーク）と同じように示します。どれもオンにするか開始するまではオフであるか、お客様が求めたダウンロードのために一度だけ行われます。

1つのスイッチで完全オフライン

「Settings › Privacy & network」の「Fully offline」（完全オフライン）は、すべてのオンライン機能を拒否し、スマートフォンとリレーへの接続を閉じ、アップデートも含めて何もダウンロードしません。ドキュメント、受信トレイ、ローカルモデルは引き続き使えます。初回起動時に、オンラインのままにするか完全オフラインにするかを一度だけ尋ねます。

保存データの保護

「Settings › Protection」（設定 › 保護）で選べるオプションです。ノートPCの紛失、同じPCの別のユーザー、クラウドフォルダー内のバックアップに備えます。

制限事項StarkLLMが開いている間にお客様の権限で動くマルウェアからは守れません。プログラムやモデルも保護できるBitLockerの併用をおすすめします。

ディスク上で暗号化
ドキュメント、チャット、名前、タイトルはディスク上で暗号化され、検索インデックスもロックできます。鍵はお客様のWindowsアカウントに結び付けられます。
起動時のパスフレーズ
回復キー付きのオプションのパスフレーズです。パスフレーズ自体は保存されません。
暗号化されたバックアップ
どこにでも、クラウドフォルダーにも置ける1つのバックアップファイルです。パスフレーズがなければ意味のないデータにすぎません。毎週の自動バックアップは複数の世代を保持します。

署名済みのビルド

2.1.2以降、インストーラー、StarkLLM.exe、アンインストーラー、エンジンのプログラムファイルは、「Open Source Developer Christian Stark」に発行されたCertumの証明書で署名されています。内蔵のアップデーターは、この名前で署名されたアップデートだけをインストールします。

ご自身で確かめる

StarkLLM自身の画面を信じる必要はありません。「Fully offline」をオンにしてアプリを使い、確かめてください。

  1. リソースモニターWin + Rで「resmon」と入力し、「ネットワーク」タブを開きます。完全オフラインがオンなら、StarkLLM.exe、python.exe、ollama.exeの通信先は127.0.0.1だけのはずです。
  2. PowerShellこのPC以外に向かう開いている接続を、それを作ったプログラムとともにすべて一覧表示します：
    Get-NetTCPConnection -State Established |
  Where-Object { $_.RemoteAddress -notin '127.0.0.1','::1' } |
  ForEach-Object { $p = Get-Process -Id $_.OwningProcess -ErrorAction SilentlyContinue
    [pscustomobject]@{ Process = $p.ProcessName; Remote = "$($_.RemoteAddress):$($_.RemotePort)" } } |
  Sort-Object Process, Remote | Format-Table -AutoSize
  3. Wireshark最も確実な方法です。ネットワークアダプターでキャプチャし、ローカルの通信を除外します。次にウェブ検索をオンにしてDuckDuckGoが現れるのを確認すれば、この確認方法が機能していることがわかります。
