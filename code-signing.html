Code signing policy

Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

What is signed

  • The StarkLLM program (StarkLLM.exe) and the Windows installer (StarkLLM-v…-Setup.exe).
  • Both are built by GitHub Actions from the public source code in github.com/StarkChristian/StarkLLM (branch main). Files built on a developer's PC are never signed.
  • Files of other open source projects that the app ships unchanged (for example the Electron and Chromium libraries and the NSIS installer plugins) keep the signature of their authors, or none. We only sign files built from our own source code.

Team roles

  • Committers and reviewers: Christian Stark (StarkChristian).
  • Approvers: Christian Stark (StarkChristian).
  • Changes from other contributors are reviewed by a committer before they are merged.
  • Every release is approved by hand before it is signed. Nothing is signed automatically.
  • Everyone in these roles uses multi-factor authentication for GitHub and SignPath.

Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. The optional online features (web search, cloud model providers you add, imports, market prices, the update check that asks first) and the one-time downloads on the first start (the engine and the AI models) are listed on the privacy page. The program has no telemetry.

Check a download

  • In Windows: right-click the file, Properties, Digital Signatures. The signer is SignPath Foundation.
  • The SHA-256 checksum of every installer is on the download page and in the release notes on GitHub.

Report a problem

If a signed file looks wrong, or you think a release was not built from this repository, write to info@starkllm.com or open an issue at GitHub.
