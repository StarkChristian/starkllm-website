Cartas

Tus cartas y documentos de un vistazo

Añade un PDF, un escaneo o una foto hecha con el móvil. StarkLLM lo lee en tu PC, agrupa en un expediente las cartas de un mismo remitente y pone cada plazo en la página de inicio. Cada valor enlaza con la página y la línea de las que se leyó.

Las cartas y la interfaz funcionan en inglés y alemán. El reconocimiento de texto (OCR) de fotos y escaneos lee inglés y alemán. Los demás idiomas se archivan como documentos normales, sin plazos ni importes. Llegarán con las próximas versiones (en preparación, aún no publicadas): las reglas de cartas para francés, español, italiano y turco, y la interfaz en español, francés, italiano y turco. Documentos de demostración con nombres y cifras inventados.

Pensado para quienes no pueden subir sus documentos a ningún sitio.

Bandeja

Una bandeja de entrada con un expediente por remitente

De cada carta: su tipo (factura, reclamación de pago, notificación de Hacienda, contrato, multa y más), remitente, fecha, números de referencia, importes, cuentas bancarias y plazos, cada uno encontrado literalmente en una página. Marca una carta como resuelta cuando te hayas ocupado de ella. En tu disco no se cambia el nombre de nada ni se mueve nada.

Plazos

Plazos en la página de inicio

Plazos, citas y fechas de pago de tus cartas, con el importe y la página. «Add to calendar» (añadir al calendario) los guarda como archivo de calendario.

Escaneos

Las fotos y los escaneos se leen en tu PC

Una foto o una página escaneada se lee como texto en inglés o alemán, se endereza si hace falta y se puede buscar y citar como cualquier otro documento.

Seguridad

Avisos de cartas falsas

Aparece un recuadro rojo si una carta pide un pago a una cuenta extranjera, con un vale o a través de un enlace, si contiene texto dirigido a asistentes de IA, o si un remitente menciona de repente otra cuenta.

Conocimiento

Workspaces y una base de conocimiento global

Vincula carpetas de Windows, mantén los proyectos aislados y consulta la base de conocimiento compartida desde cualquier chat.

Recuperación

RAG híbrido con reordenador cross-encoder

La búsqueda por palabras clave y la búsqueda semántica se ejecutan juntas; después, un cross-encoder TinyBERT reordena los pasajes que de verdad responden a la pregunta.

Escritorio

Una ventana de aplicación de verdad

Ventana propia con pantalla de inicio y menú en la bandeja del sistema. Sin pestaña del navegador.

Temas

Trece temas, que se cambian al instante

Desde Midnight Indigo y el negro puro OLED hasta Daylight Minimal, más cinco temas con motivos como Doodle Chat y Starry Night.

Herramientas

Herramientas locales con puerta de confirmación

Herramientas de solo lectura como search_local_kb y fetch_cited_chunk. Cada llamada necesita tu confirmación y un token de un solo uso.

Otras aplicaciones

Usa StarkLLM desde otros programas (desactivado por defecto)

Editores como VS Code y Cursor, asistentes de IA compatibles con MCP y tus propios scripts pueden buscar en tus documentos y hacerles preguntas a través de un servidor MCP o de una API compatible con OpenAI. Solo en este PC, solo con una clave que crees tú, y no pueden modificar ni borrar nada.

Código

Sandbox local de Python

Se ejecuta dentro de la aplicación, con comprobaciones del código y límites de tiempo y de memoria. Es un límite de comodidad, no una frontera de seguridad: ejecuta solo código de confianza.

Instalación en tres pasos

Instala Docker Desktop y Ollama una sola vez; StarkLLM hace el resto. El primer arranque descarga unos 5 GB y construye el motor (de 10 a 20 minutos); los siguientes arranques tardan segundos.

  1. Instala Docker DesktopDesde docker.com (con WSL2). Ábrelo una vez y termina su configuración.
  2. Instala OllamaDesde ollama.com. No hace falta terminal: StarkLLM descarga los modelos por sí mismo.
  3. Instala y abre StarkLLMEjecuta StarkLLM-v2.1.2-Setup.exe y haz clic en el acceso directo. La aplicación inicia Docker y Ollama, descarga los modelos, construye su motor y muestra el progreso.
  4. Si falta algoLa ventana indica qué falta y cómo solucionarlo, con un botón Retry (reintentar). La página de ayuda tiene una lista de comprobación.

Notas importantes

Primer arranque. Puede tardar varios minutos mientras se descargan las imágenes de Docker. Una vez que los contenedores están en marcha, el backend puede necesitar otros 1–2 minutos para terminar de arrancar.

Windows SmartScreen. Si se bloquea la ejecución, elige More info (Más información) y después Run anyway (Ejecutar de todas formas).

El hardware importa. La velocidad y la calidad de las respuestas dependen mucho de una GPU potente (se recomiendan 8 GB o más de VRAM).

La arquitectura de la privacidad

StarkLLM es una alternativa sin conexión a los servicios de IA en la nube. Tus documentos, escritos jurídicos e investigaciones se quedan en tu equipo.

Inferencia local

Con Ollama, los modelos de lenguaje se ejecutan en tu propia CPU o GPU. Diseñado para funcionar totalmente sin conexión una vez descargados los modelos.

Almacenamiento local

Los documentos se dividen en fragmentos y se incrustan en un almacén vectorial ChromaDB local que se ejecuta en un contenedor de Docker aislado.

Cero telemetría

La aplicación de Windows no tiene telemetría ni ningún SDK de analítica. Este sitio web usa Umami, alojado por nosotros mismos; consulta la información legal.

Conexión solo cuando tú lo eliges

La búsqueda web, los proveedores de modelos en la nube, la importación de YouTube y GitHub, las cotizaciones de mercado y la comprobación de actualizaciones están desactivados hasta que los actives. El chat muestra cuándo una petición sale de tu PC.
