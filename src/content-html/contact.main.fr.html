Comment obtenir de l’aide

Selon l’aide dont vous avez besoin, voici les moyens les plus efficaces d’atteindre la bonne ressource :

  • Problèmes d’installation ou de configuration : commencez par la page Aide et dépannage. Elle propose une liste de contrôle de l’installation avec un test pour chaque étape et des solutions aux problèmes les plus fréquents (Docker Desktop, WSL2, Ollama, modèles, ports). Le manuel d’utilisation présente l’application elle-même.
  • Rapports de bogue : si vous avez rencontré un plantage de l’application ou une erreur inattendue lors de l’ingestion d’un document, ouvrez un ticket sur GitHub Issues en indiquant les caractéristiques de votre système et les étapes pour reproduire le problème.
  • Signalement responsable de failles de sécurité : si vous avez découvert une faille locale potentielle, écrivez-nous directement à info@starkllm.com avec le préfixe [Security] dans l’objet, avant toute divulgation publique.
  • Matériel et taille des modèles : vous vous demandez si votre machine peut exécuter confortablement des modèles Qwen, Mistral ou Llama ? Consultez notre guide des modèles locaux ou posez la question dans les GitHub Discussions.

Questions fréquentes

StarkLLM est-il vraiment 100 % gratuit et open source ?

Oui. StarkLLM est fourni sous une licence open source. Il n’y a ni abonnement, ni frais cachés de cloud, ni accès à l’API réservé aux payants.

StarkLLM transmet-il des données de requêtes à des serveurs externes ?

Seulement si vous l’activez. La génération de texte, les embeddings vectoriels, le découpage des documents et la base de données s’exécutent en local sur votre PC. Rien ne quitte votre PC, sauf si vous activez une fonction en ligne facultative (recherche web, fournisseur de modèles dans le cloud, vérification des mises à jour).

Où puis-je télécharger la dernière version ?

Rendez-vous sur la page de téléchargement pour obtenir l’installeur Windows officiel et vérifier les sommes de contrôle SHA-256.
