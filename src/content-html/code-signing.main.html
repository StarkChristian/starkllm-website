Code signing policy

How StarkLLM for Windows is signed

Releases are signed with a Certum Open Source Code Signing certificate issued to “Open Source Developer Christian Stark” (the key is in Certum’s cloud, SimplySign; every signing session is confirmed on the owner’s phone).

  • What is signed: StarkLLM.exe, its uninstaller and the Windows installer. The app is built by GitHub Actions (desktop-release.yml) from a tagged commit of the main branch; the signatures are added on the owner’s PC (docs/signing-on-owner-pc.md), and the app checks that every update carries the same publisher name. Files of other open source projects that the app ships unchanged (Electron and Chromium libraries, NSIS installer plugins) keep their authors’ signature, or none.
  • Committers and reviewers: Christian Stark (StarkChristian). Changes from other contributors are reviewed by a committer before they are merged.
  • Approvers: Christian Stark (StarkChristian). Every release is approved by hand before it is signed.
  • Everyone in these roles uses multi-factor authentication for GitHub and Certum SimplySign.
  • Privacy: This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. The optional online features and the one-time downloads on the first start are listed on the privacy page. The program has no telemetry.
