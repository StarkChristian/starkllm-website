Come ottenere assistenza

A seconda di ciò per cui ti serve aiuto, ecco i modi più efficaci per raggiungere la risorsa giusta:

  • Problemi di installazione o di configurazione: consulta prima il nostro Manuale d'uso dettagliato. Tratta la configurazione di Docker, l'impostazione dei modelli Ollama, l'accelerazione GPU e la risoluzione dei conflitti di porte.
  • Segnalazioni di bug: se hai riscontrato un arresto anomalo dell'applicazione o un errore imprevisto durante l'acquisizione dei documenti, apri una issue su GitHub Issues indicando le specifiche del sistema e i passaggi per riprodurre il problema.
  • Segnalazioni responsabili di sicurezza: se hai scoperto una possibile vulnerabilità locale, scrivici direttamente a info@starkllm.com con il prefisso [Security] nell'oggetto, prima di qualsiasi divulgazione pubblica.
  • Hardware e dimensioni dei modelli: ti chiedi se il tuo computer riesca a eseguire senza problemi i modelli Qwen, Mistral o Llama? Consulta la nostra guida ai modelli locali oppure chiedi nelle GitHub Discussions.

Domande frequenti

StarkLLM è davvero gratuito al 100% e open source?

Sì. StarkLLM è fornito con una licenza open source. Non ci sono abbonamenti, costi nascosti per il cloud né paywall sulle API.

StarkLLM trasmette dati dei prompt a server esterni?

Zero. Tutta la generazione dei token, gli embedding vettoriali, la divisione dei documenti in chunk e l'archiviazione nel database avvengono in locale sulla tua macchina fisica.

Dove posso scaricare l'ultima versione?

Visita la pagina di download per ottenere l'installer ufficiale per Windows e verificare i checksum di integrità SHA-256.
