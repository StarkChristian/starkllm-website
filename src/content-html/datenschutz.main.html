3. Datenerfassung auf unserer Website

Hosting und Server-Log-Dateien

Diese Website besteht aus statischen Seiten. Sie wird über Cloudflare Pages bereitgestellt, und alle Aufrufe von starkllm.com laufen über das Netzwerk von Cloudflare (Anbieter: Cloudflare, Inc., USA). Den Quellcode der Website verwalten wir bei GitHub (GitHub, Inc., USA, ein Tochterunternehmen der Microsoft Corporation); beim Aufruf der Seiten werden dorthin keine Daten übertragen.

Beim Aufrufen unserer Website sendet der Browser Ihres Endgeräts automatisch Informationen an die Server von Cloudflare. Dabei werden folgende Daten verarbeitet und von Cloudflare in Protokolldateien (Server-Logs) gespeichert:

  • IP-Adresse des anfragenden Rechners
  • Datum und Uhrzeit des Zugriffs
  • Name und URL der abgerufenen Datei
  • Website, von der aus der Zugriff erfolgt (Referrer-URL)
  • Verwendeter Browser und ggf. das Betriebssystem Ihres Rechners

Cloudflare verarbeitet diese Daten, um die Seiten auszuliefern und die Website vor Angriffen und Missbrauch zu schützen. Bei Verbindungsfehlern kann Ihr Browser außerdem einen technischen Fehlerbericht (Network Error Logging) an Cloudflare senden. Cloudflare verschleiert E-Mail-Adressen auf diesen Seiten gegen Spam-Programme; dafür lädt Ihr Browser ein kleines Skript von dieser Domain. Wir selbst werten diese Daten nicht aus und erstellen keine Nutzungsprofile.

Die Rechtsgrundlage für die Datenverarbeitung ist Art. 6 Abs. 1 S. 1 lit. f DSGVO. Unser berechtigtes Interesse folgt aus den Zwecken zur Gewährleistung eines reibungslosen Verbindungsaufbaus der Website und Gewährleistung der Systemsicherheit und -stabilität. Cloudflare kann Daten auch in den USA verarbeiten. Die Übermittlung stützt sich auf den Angemessenheitsbeschluss der EU-Kommission zum EU-US Data Privacy Framework, unter dem Cloudflare, Inc. zertifiziert ist. Weitere Informationen: Datenschutzerklärung von Cloudflare.

4. Lokale StarkLLM-Software (Desktop App)

Die StarkLLM Windows-Anwendung arbeitet nach dem Prinzip Local-First:

  • Alle Dokumente, Vektordatenbanken (ChromaDB) und Benutzerkonten werden ausschließlich lokal auf Ihrem Computer gespeichert.
  • Die Sprachmodelle laufen über Ollama lokal auf Ihrer CPU/GPU.
  • Es werden durch die Software keine Telemetrie- oder Nutzungsdaten an externe Server übertragen.

Folgende Funktionen stellen nur dann eine Verbindung ins Internet her, wenn Sie sie selbst einschalten oder auslösen:

  • Websuche (Schalter im Chat): Ihre Frage wird an DuckDuckGo gesendet. Nur wenn DuckDuckGo nicht antwortet, geht sie an Mullvad Leta und danach an Mojeek, jeweils an nur einen Anbieter.
  • Web-Aufgaben (Schalter „Web-Aufgabe“ im Chat): StarkLLM öffnet die Websites der Aufgabe in einem eigenen Fenster. Die Betreiber dieser Websites erhalten Ihre IP-Adresse und das, was bei der Aufgabe dort eingegeben wird.
  • Cloud-Modellanbieter (Einstellungen, z. B. DeepSeek, OpenRouter, Groq): Ihre Frage und die gefundenen Dokumentabschnitte werden an den gewählten Anbieter gesendet.
  • Cloud-Modelle von Ollama (Modelle, deren Name auf „:cloud“ endet): Ihre Frage und die gefundenen Dokumentabschnitte werden über Ollama an die Server von Ollama gesendet.
  • Import aus dem Web (Webseite, YouTube, GitHub): Die App lädt die angegebene Webseite, das Video-Transkript bzw. das Repository herunter.
  • OCR-Sprachpakete (Einstellungen › Fotos und Scans lesen): Die gewählte Sprachdatei wird von GitHub geladen.
  • Marktpreise (Widget, standardmäßig aus): Abruf bei Yahoo Finance und CoinGecko.
  • Update-Prüfung (beim ersten Start gefragt, jederzeit abschaltbar): Abfrage der neuesten Version bei GitHub, ohne Nutzungsdaten.

Für diese Verbindungen gelten die Datenschutzbestimmungen des jeweiligen Anbieters. Einstellungen › Datenschutz & Netzwerk listet alle Verbindungen der App, und der Schalter „Vollständig offline“ verhindert sie alle. Befehle, die Sie im Terminal erlauben, und Werkzeug-Server (MCP), die Sie selbst hinzufügen, laufen als Ihre eigenen Programme; ihre Verbindungen stehen nicht in dieser Liste.

Telefon-Verbindung im Heimnetz: Nur wenn Sie unter Einstellungen › Telefon die Verbindung einschalten und ein Telefon koppeln, kann dieses gekoppelte Telefon die App über Ihr Heimnetz erreichen. Dabei werden keine Daten ins Internet übertragen.

Einmalige Downloads ohne Ihre Daten: Die von Ihnen gewählten KI-Modelle (über Ollama), das Bildmodell (über Ollama, bei der ersten Frage zu einem Bild), das Spracherkennungsmodell Whisper base (bei der ersten Spracheingabe) und Whisper large-v3-turbo (etwa 1,6 GB, bei der ersten Aufnahme) werden einmalig aus dem Internet geladen. Dabei werden keine Dokumente, Fragen oder Nutzungsdaten übertragen. Das Re-Ranking-Modell der Suche ist Teil der App und funktioniert auch ohne Internet.
