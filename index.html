Set up in three steps

Install Docker Desktop and Ollama once; StarkLLM does the rest. The first start downloads about 5 GB and builds the engine (10 to 20 minutes); later starts take seconds.

  1. Install Docker DesktopFrom docker.com (with WSL2). Start it once and finish its setup.
  2. Install OllamaFrom ollama.com. No terminal needed: StarkLLM downloads the models itself.
  3. Install and start StarkLLMRun StarkLLM-v2.0.1-Setup.exe (or the portable build) and click the shortcut. The app starts Docker and Ollama, downloads the models, builds its engine and shows the progress.
  4. If something is missingThe window says what is missing and how to fix it, with a Retry button. The Help page has a checklist.

Important notes

First launch. It can take several minutes while Docker images download. After the containers are up, the backend may need another 1–2 minutes to finish starting.

Windows SmartScreen. If execution is blocked, choose More info, then Run anyway.

Hardware matters. Speed and answer quality depend heavily on a capable GPU (8 GB+ VRAM recommended).

The architecture of privacy

StarkLLM is an offline alternative to cloud AI services. Your documents, legal briefs and research stay on your machine.

Local inference

Powered by Ollama, language models run on your own CPU or GPU. Designed to work fully offline once models are downloaded.

Local storage

Documents are chunked and embedded into a local ChromaDB vector store running in an isolated Docker container.

Zero telemetry

The Windows app has no telemetry and no analytics SDK. This website uses self-hosted Umami analytics; see the Datenschutz page.
