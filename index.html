New in 2.5.0

StarkLLM now does tasks for you.

On websites, in a project folder and from your phone. You see every step, and it asks before anything that matters. Your documents and the AI model stay on your PC.

  • Web tasks in its own browser window

    StarkLLM opens its own browser window and works on websites, for example to find the cheapest flight on a day. You see every step. It asks before anything that buys, books, pays, sends or deletes. Sign-ins, payments and "are you a robot" checks always stay with you. A task can be repeated daily or weekly.

  • Help with code in a project folder

    Choose a folder with "Terminal": StarkLLM reads and changes files there and runs PowerShell commands. Every change is shown first, every command that can change something runs only after your yes, and "Undo the file changes" puts the files back.

  • Questions about an image

    Paste a screenshot or choose a photo, and a vision model on your PC answers. The image is made smaller, its hidden data (place, camera) is removed, and it is not stored.

  • Recordings become documents

    Meetings, lectures and voice memos are written down on your PC with times, by Whisper large-v3-turbo (downloaded once, about 1.6 GB). Then you ask about them like about any document.

  • Two models side by side

    "Compare models" asks a second local model the same question. You keep the better answer.

  • Word and PDF, with sources

    Save a whole chat or a single answer as a Word document or a PDF, with the sources it is based on.

  • Your own tool servers (MCP)

    Add MCP servers that run on your PC in Settings › Local Tools. Every tool is off until you turn it on, and every call waits for your yes.

  • Your Android phonePreview

    Pair the StarkLLM app for Android by QR code, then ask about your documents, send photos of letters and see your deadlines. Home network only, encrypted with a certificate the phone checks. Per phone you choose: ask only, also send documents, or also manage this PC.

  • Web search with fallback engines

    When you turn on web search, your question goes to DuckDuckGo. Only if it does not answer, StarkLLM tries Mullvad Leta, then Mojeek: one engine at a time, never several at once.

Web tasks and the terminal work best with a local model of 14B or more (for example qwen3:14b); small 7B models stop safely but finish few tasks. How the new features work

Letters

Your letters and documents at a glance

Add a PDF, a scan or a photo from your phone. StarkLLM reads it on your PC, groups the letters of one sender into a case and puts every deadline on the start page. Each value links to the page and line it was read from.

Letters are read in English, German, French, Spanish, Italian and Turkish, with their deadlines and amounts, and the interface speaks the same six languages. Text recognition (OCR) for photos and scans reads English and German out of the box; more languages can be added in Settings. Letters in other languages are filed as ordinary documents, without deadlines and amounts. Demo documents with invented names and numbers.

Built for people who can't upload their documents.

Inbox

An inbox with a case per sender

For every letter: its kind (bill, reminder, tax notice, contract, fine and more), sender, date, reference numbers, amounts, bank accounts and deadlines, each found word for word on a page. Mark a letter done when you have dealt with it. Nothing is renamed or moved on your disk.

Deadlines

Deadlines on the start page

Deadlines, appointments and payment dates from your letters, with the amount and the page. "Add to calendar" saves them as a calendar file.

Scans

Photos and scans are read on your PC

A photo or scanned page is read as English or German text, turned upright if needed, and can be searched and cited like any other document.

Safety

Warnings for fake letters

A red box appears if a letter asks for payment to a foreign account, by voucher or through a link, contains text addressed to AI assistants, or a sender suddenly names a different account.

Knowledge

Workspaces and a global knowledge base

Map Windows folders, keep projects isolated, and query the shared knowledge base from any chat.

Retrieval

Hybrid RAG with a cross-encoder re-ranker

Keyword and semantic search run together, then a TinyBERT cross-encoder re-ranks the passages that actually answer the question.

Desktop

A real app window

Its own window with splash screen and tray menu. No browser tab.

Themes

Thirteen themes, switched instantly

From Midnight Indigo and pure OLED black to Daylight Minimal, plus five pattern themes such as Doodle Chat and Starry Night.

Tools

Local tools with a confirmation gate

Read-only tools such as search_local_kb and fetch_cited_chunk. Every call needs your confirmation and a single-use token.

Other apps

Use StarkLLM from other programs (off by default)

Editors such as VS Code and Cursor, MCP-capable AI assistants and your own scripts can search your documents and ask questions about them through an MCP server or an OpenAI-compatible API. Only on this PC, only with a key you create, and they cannot change or delete anything.

Code

Local Python sandbox

Runs Python code blocks from the chat with code checks and time and memory limits. Available with the Docker Desktop engine (advanced); off in the built-in engine until StarkLLM has its own sandbox. A convenience limit, not a security boundary: only run code you trust.

Set up in four steps

StarkLLM brings its own engine: no Docker Desktop, no WSL2. The first start downloads the AI models (about 5 GB) and, if you let it, Ollama; later starts take seconds.

  1. Install StarkLLMRun StarkLLM-v2.5.0-Setup.exe and click the shortcut. The installer is signed by "Open Source Developer Christian Stark" and contains the engine.
  2. Let it set up OllamaIf Ollama is missing, choose "Install Ollama for me": StarkLLM installs the official, signed version. No terminal needed.
  3. Wait for the modelsStarkLLM downloads the AI models it needs, shows the progress and then opens in its own window.
  4. If something is missingThe window says what is missing and how to fix it, with a Retry button. The Help page has a checklist.

Important notes

First launch. Downloading the AI models (about 5 GB) takes a while on a slow connection. The first start after an install or update can also take a few minutes while the engine starts.

Windows SmartScreen. The installer is signed by "Open Source Developer Christian Stark". If Windows still warns, check that publisher name (right-click the installer, Properties, Digital Signatures) and compare the SHA-256 checksum on the download page. Continue (More info, then Run anyway) only if both match, and do not turn off SmartScreen or Smart App Control.

Hardware matters. Speed and answer quality depend heavily on a capable GPU (8 GB+ VRAM recommended).

Privacy you can check

StarkLLM is built so that your documents never need a cloud. What goes online is your choice, and you can see it.

  • Documents and model stay on your PC

    Your documents, chats and search index are stored on your own disk, and the language models run on your own CPU or GPU through Ollama. The phone app talks to your PC, not to a server of ours.

  • No telemetry

    The Windows app has no telemetry and no analytics SDK. This website uses no analytics and sets no cookies either; see the privacy policy.

  • Every connection listed

    Web search, web tasks, cloud model providers, imports from the web (web pages, YouTube, GitHub), market prices and the update check run only when you turn them on or start them. Settings › Privacy & network lists every connection StarkLLM makes; commands you allow in Terminal and tool servers you add run as your own programs and are not listed. The chat shows when a question leaves your PC.

  • Fully offline switch

    One switch takes StarkLLM fully offline: every online feature is refused and the link to your phone is closed. Your documents, the inbox and the local models keep working.
