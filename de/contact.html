So bekommen Sie Hilfe

Je nachdem, wobei Sie Hilfe brauchen, führen diese Wege am schnellsten zur richtigen Quelle:

  • Probleme bei Installation oder Einrichtung: Beginnen Sie mit Hilfe & Problemlösung. Dort finden Sie eine Installations-Checkliste mit einem Test pro Schritt und Lösungen für die häufigsten Probleme (Ollama, Modelle, Ports, Windows-Sicherheitswarnungen). Das Handbuch erklärt die App selbst.
  • Fehlerberichte: Wenn die Anwendung abgestürzt ist oder beim Einlesen von Dokumenten ein unerwarteter Fehler auftrat, eröffnen Sie bitte ein Issue auf GitHub Issues mit Systemdaten und nachvollziehbaren Schritten.
  • Verantwortungsvolle Meldung von Sicherheitslücken: Wenn Sie eine mögliche lokale Schwachstelle entdeckt haben, schreiben Sie uns vor einer Veröffentlichung bitte direkt an info@starkllm.com mit dem Betreffpräfix [Security].
  • Hardware & Modellgröße: Sie fragen sich, ob Ihr Rechner Qwen-, Mistral- oder Llama-Modelle komfortabel ausführt? Lesen Sie unseren Leitfaden zu lokalen Modellen oder fragen Sie in den GitHub Discussions.

Häufige Fragen

Ist StarkLLM wirklich zu 100 % kostenlos und Open Source?

Ja. StarkLLM steht unter einer Open-Source-Lizenz. Es gibt keine Abonnements, versteckten Cloud-Gebühren oder API-Bezahlschranken.

Überträgt StarkLLM Eingaben an externe Server?

Nur wenn Sie es einschalten. Textgenerierung, Vektor-Einbettungen, Zerlegung der Dokumente und Datenspeicherung laufen lokal auf Ihrem Rechner. Nichts verlässt Ihren PC, außer Sie schalten eine optionale Online-Funktion ein: Websuche, eine Web-Aufgabe, einen Cloud-Modellanbieter, einen Import aus dem Web, Marktpreise, das Handy unterwegs (über das StarkLLM-Relay) oder die Update-Prüfung. Einstellungen › Datenschutz & Netzwerk listet sie auf, und „Vollständig offline“ lehnt sie alle ab.

Wo lade ich die neueste Version herunter?

Auf der Download-Seite erhalten Sie den offiziellen Windows-Installer und die SHA-256-Prüfsummen zur Kontrolle.
