Suche

Hybrides RAG mit Cross-Encoder-Reranker

Stichwort- und semantische Suche laufen zusammen; ein TinyBERT-Cross-Encoder sortiert die Treffer neu und stellt die Passagen nach oben, die die Frage wirklich beantworten.

Desktop

Ein echtes App-Fenster

Eigenes Fenster mit Startbildschirm und Tray-Menü. Kein Browser-Tab.

In etwa fünf Minuten eingerichtet

Sind Docker, Ollama und die Modelle bereits installiert, dauert die Einrichtung etwa 5 Minuten. Der erste Download von Modellen und Docker-Images hängt von Ihrer Bandbreite ab.

  1. Docker Desktop startenStellen Sie sicher, dass es im Infobereich läuft.
  2. Ollama installieren und Modelle ladenFühren Sie im Terminal Folgendes aus:
    ollama pull qwen2.5:7b
ollama pull nomic-embed-text
  3. Projekt holen und Dienste startenDie Desktop-App zeigt StarkLLM nur an; sie startet die Dienste nicht. Laden Sie das Projekt von GitHub herunter, entpacken Sie es und starten Sie start.cmd (Auswahl 1) oder führen Sie aus:
    docker compose up --build -d
  4. StarkLLM-Installer ausführenStarkLLM-v2.0.0-Setup.exe herunterladen und starten, oder die portable Version nutzen. Der Assistent legt die Verknüpfungen an.
  5. StarkLLM startenKlicken Sie auf die Desktop-Verknüpfung. Das Fenster lädt, sobald die Dienste laufen.

Wichtige Hinweise

Erster Start. Er kann einige Minuten dauern, während Docker-Images geladen werden. Sobald die Container laufen, braucht das Backend eventuell noch 1–2 Minuten.

Windows SmartScreen. Wird die Ausführung blockiert, wählen Sie „Weitere Informationen“ und dann „Trotzdem ausführen“.

Hardware zählt. Geschwindigkeit und Antwortqualität hängen stark von einer leistungsfähigen GPU ab (8 GB+ VRAM empfohlen).

Die Architektur der Privatsphäre

StarkLLM ist eine Offline-Alternative zu Cloud-KI-Diensten. Ihre Dokumente, Schriftsätze und Recherchen bleiben auf Ihrem Rechner.

Lokale Inferenz

Mit Ollama laufen Sprachmodelle auf Ihrer eigenen CPU oder GPU. Nach dem Download der Modelle ist der Betrieb vollständig offline möglich.

Lokaler Speicher

Dokumente werden in Chunks zerlegt und in einen lokalen ChromaDB-Vektorspeicher in einem isolierten Docker-Container eingebettet.

Keine Telemetrie

Die Windows-App enthält weder Telemetrie noch ein Analyse-SDK. Diese Website nutzt selbst gehostetes Umami; siehe Datenschutzerklärung.
