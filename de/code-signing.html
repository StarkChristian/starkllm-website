Code-Signing-Richtlinie

Code-Signing-Richtlinie

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Was signiert wird

  • Das Programm StarkLLM (StarkLLM.exe) und der Windows-Installer (StarkLLM-v…-Setup.exe).
  • Beide baut GitHub Actions aus dem öffentlichen Quellcode in github.com/StarkChristian/StarkLLM (Branch main). Dateien, die auf dem PC eines Entwicklers gebaut wurden, werden nie signiert.
  • Dateien anderer Open-Source-Projekte, die die App unverändert mitliefert (zum Beispiel die Bibliotheken von Electron und Chromium und die Plugins des NSIS-Installers), behalten die Signatur ihrer Autoren oder bleiben unsigniert. Wir signieren nur Dateien, die aus unserem eigenen Quellcode gebaut werden.

Rollen im Team

  • Committer und Reviewer: Christian Stark (StarkChristian).
  • Freigabe (Approver): Christian Stark (StarkChristian).
  • Änderungen anderer Mitwirkender prüft ein Committer, bevor sie übernommen werden.
  • Jede Version wird von Hand freigegeben, bevor sie signiert wird. Nichts wird automatisch signiert.
  • Alle in diesen Rollen nutzen Mehr-Faktor-Authentifizierung für GitHub und SignPath.

Datenschutz

Dieses Programm überträgt keine Informationen an andere vernetzte Systeme, außer der Nutzer oder die Person, die es installiert oder betreibt, verlangt es ausdrücklich. Die optionalen Online-Funktionen (Websuche, selbst hinzugefügte Cloud-Modellanbieter, Importe, Marktpreise, die Update-Prüfung, die vorher fragt) und die einmaligen Downloads beim ersten Start (die Engine und die KI-Modelle) stehen auf der Datenschutz-Seite. Das Programm hat keine Telemetrie.

Einen Download prüfen

  • In Windows: Rechtsklick auf die Datei, Eigenschaften, Digitale Signaturen. Signiert hat SignPath Foundation.
  • Die SHA-256-Prüfsumme jedes Installers steht auf der Download-Seite und in den Release-Notes auf GitHub.

Ein Problem melden

Wenn eine signierte Datei verdächtig aussieht oder Sie glauben, dass eine Version nicht aus diesem Repository gebaut wurde, schreiben Sie an info@starkllm.com oder öffnen Sie ein Issue auf GitHub.
