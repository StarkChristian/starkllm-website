How StarkLLM Works

An end-to-end local pipeline designed with data privacy in mind.

The Document Lifecycle

When you upload a PDF or text file into StarkLLM, processing stays local to your PC. First, local parsers extract the raw text (scanned PDFs and images go through local OCR / vision before chunking). Second, a Semantic Chunking algorithm splits the text into logical, overlapping blocks. Third, a local embedding model converts these blocks into vectors, storing them in your private ChromaDB container. Finally, when you ask a question, the system retrieves the most relevant passages and injects them into the context window of your chosen Ollama LLM, producing source-grounded responses.

Verifiable Intelligence

Large Language Models can produce unsupported claims when answering from memory alone. StarkLLM addresses this through Retrieval-Augmented Generation (RAG).

  • Source-Backed Responses: The AI retrieves verified text passages from your exact documents before formulating an answer.
  • Direct Citations: Responses include citations with the source filename and page or section locator, so you can find the relevant passage in your original document.
  • Reduced Hallucination: Grounding the generation in your documents drastically reduces unsupported statements.

Your Persistent Library

While workspace uploads are great for isolated projects, the Global Knowledge Base acts as your permanent, universally accessible reference library.

  • Local Folder Indexing: Map any folder on your Windows machine to StarkLLM. The system will recursively index supported files into a global vector collection.
  • Universal Access: Query your Knowledge Base from any active chat session, regardless of the current workspace you are in.
  • Interval Synchronization: The Knowledge Base checks your mapped folder approximately every minute and re-indexes new or modified files automatically.

Workspace vs Knowledge Base

StarkLLM offers two ways to contextualize the AI. Understanding the difference is critical to organizing your intelligence.

Workspace Documents

  • Tied strictly to one single workspace.
  • Useful when work must stay isolated to prevent context contamination.
  • Best for temporary or project-specific document sets.
Example:
A folder of contracts for one specific legal case or client audit.

Knowledge Base

  • A persistent, global intelligence layer.
  • Useful across all chats and ongoing workspaces simultaneously.
  • Best for long-term reference material and personal archives.
Example:
Your ongoing, permanent research library, handbook, or company SOPs.

Local Control

StarkLLM provides deep administrative control over your local inference environment, empowering you to tune performance to your exact hardware capabilities.

  • Model Selection: Switch seamlessly between any LLM downloaded via Ollama (e.g., Qwen 2.5, Llama 3.2, Mistral) directly from the chat interface.
  • Runtime Configuration: Adjust context window sizes, temperature, and advanced parameters to balance speed and reasoning depth.
  • Strict Localhost Routing: All internal API communication runs on localhost Docker and host ports, keeping your data strictly on your machine.

In-Process Local MCP Host

Unlike cloud AI tools that execute commands remotely, StarkLLM implements an in-process local tool host directly within FastAPI, giving models verified read-only access to your indexed content.

  • Three Built-in Tools: list_workspace_files (inspects active tenant files), search_local_kb (hybrid vector and BM25 search over personal archives), and fetch_cited_chunk (fetches exact passage text).
  • Human-in-the-Loop Gate: Tool executions generate an interactive card in the chat UI. You can review the parameters, modify values, or cancel execution entirely.
  • Adversarial Prompt Defense: Vector search passages are stripped of tool call markers before reaching the model context, eliminating prompt injection risks.

⚡ Technical Superiority

Why StarkLLM Outperforms Traditional Local AI

While other desktop clients offer basic chat wrappers or naive document chunking, StarkLLM is engineered as a robust, precision-grade AI workstation.

🎯 Hybrid RAG + Cross-Encoder

Most desktop RAG tools rely solely on naive vector embeddings, missing exact keywords or returning irrelevant chunks. StarkLLM merges BM25 keyword frequency with dense vector search, passing results through a local TinyBERT Cross-Encoder to re-rank chunks with mathematical precision.

🖥️ Native Standalone Window (v2.0.0)

No browser tabs or web address bars. StarkLLM runs as a standalone desktop application with smooth frameless titlebars, dedicated splash screens, system tray background integration, and official Windows NSIS installers.

⚡ In-Process Code Sandbox

Execute Python calculations, data analysis, and formula derivations safely on your own machine. Protected by strict AST validation, memory caps, and timeout watchdogs without exposing your OS or network.

🔌 Universal OpenAI Local API

A drop-in local gateway exposing /v1/chat/completions and /v1/models. Connect IDEs like Cursor, tools like Claude Code, Obsidian plugins, or custom Python scripts directly to your local models.
