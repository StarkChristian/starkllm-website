Confidentialité

Ce qui reste sur votre PC

Les documents, l’index, les discussions et les modèles restent sur votre ordinateur. Quelques fonctions facultatives se connectent à internet, et seulement quand vous les utilisez.

Vos documents, votre index de recherche, vos discussions et vos modèles restent sur ce PC. Quelques fonctions supplémentaires peuvent se connecter à internet, mais seulement si vous les activez, et la discussion vous indique quand une question quitte votre PC.

De quoi il s’agit

StarkLLM fait tourner sa base de données, son index de recherche et son interface web sur votre PC (dans son propre moteur, sans Docker depuis la v2.2), et le modèle de langage dans Ollama, lui aussi sur votre PC. Il n’a ni télémétrie ni compte sur un serveur.

Pourquoi c’est important

Des contrats, des dossiers de patients ou des données de recherche ne devraient pas être envoyés à un service cloud juste pour poser une question à leur sujet.

Fonctions en ligne facultatives

Elles ne se connectent à internet que lorsque vous les activez ou les lancez. La discussion indique quand une question quitte votre PC.

  • Recherche web (interrupteur dans la discussion) : votre question est envoyée à DuckDuckGo.
  • Fournisseurs de modèles dans le cloud (Settings, par exemple DeepSeek, OpenRouter, Groq) : votre question et les passages trouvés sont envoyés à ce fournisseur.
  • Import depuis YouTube et GitHub : l’application télécharge la transcription ou le dépôt que vous avez indiqué.
  • Cours de marché (widget, désactivé par défaut) : récupérés sur Yahoo Finance.
  • Vérification des mises à jour (demandée une fois au premier démarrage) : demande à GitHub le numéro de la version la plus récente, rien d’autre.

Téléchargements ponctuels

Les modèles d’IA (depuis Ollama), le reclasseur (à la première recherche), le modèle de reconnaissance vocale (à la première saisie vocale) et le modèle d’image (à la première image) sont téléchargés une seule fois. Aucun document, aucune question ni aucune donnée d’usage n’est envoyé avec eux.

Exemple

Après le premier démarrage, vous pouvez couper le Wi-Fi. L’ajout de documents, la recherche et les réponses continuent de fonctionner.
